# Switch Java Launcher (Mekanism Ready)

## Installation sur la SD
1. Placez `MonLauncher.nro` dans `/switch/MonLauncher/`.
2. Placez votre moteur Java ARM64 dans `/switch/MonLauncher/bin/java`.
3. Mettez vos mods (Mekanism) dans `/switch/MonLauncher/.minecraft/mods/`.

## Compilation
Le projet compile automatiquement via GitHub Actions à chaque "Push".
